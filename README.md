# CaHoOtS?

A playful multiplayer quiz-platform starter built with Next.js, React, TypeScript, and Supabase.

**Start here:** read [`SETUP.md`](./SETUP.md) for the complete installation, Google OAuth, database, and run instructions.

This is a prototype foundation. It is not a complete production Kahoot replacement yet; the live synchronized host/player engine and networked pArKoUr? mode are the next major implementation milestones.
